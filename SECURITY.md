# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature in the repository's **Security** tab. Include the affected component, reproduction steps, impact, and any suggested mitigation.

Do not publish statements, transaction data, credentials, or exploit details in a public issue. If private reporting is temporarily unavailable, open a minimal issue asking the maintainers for a private contact channel.

## Data responsibility

Statement PDFs and generated dashboards can contain highly sensitive financial data. They are excluded from this repository, but operators are responsible for reviewing artifacts before deployment, restricting access, protecting backups, and removing sensitive build output when it is no longer needed.
